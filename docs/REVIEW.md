## Исправлено

- Убран крупный рекламный первый экран и повторяющийся текст карточек.
- Источники, документы и заметки раскрываются по запросу, а список выбора виден отдельно.
- Добавлены OSQ Group и ЭФКО по официальным сайтам.
- Выбор компаний и статус контакта восстанавливаются после обновления.
- Смена статуса сохраняет раскрытые условия.
- Запрос по выпечке находит ПУРАТОС.
- На телефоне пустой список не занимает место двумя неактивными кнопками.
- При переполнении списка заблокировано четвёртое добавление, существующие компании доступны для удаления.
- Заметки выводятся текстом, начало формул в CSV нейтрализуется.
