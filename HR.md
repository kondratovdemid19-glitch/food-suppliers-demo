# Описание решения

Каталог помогает закупщику выбрать поставщиков для кухни или магазина, проверить источники, сравнить условия и подготовить одинаковый запрос коммерческого предложения.

Есть поиск товара и региона, фильтры категорий, сравнение трёх компаний, заметки, статусы контакта и выгрузка сравнения. Запрос закупки можно отредактировать и сохранить; сервис сам ничего не отправляет. Список и заметки сохраняются в браузере.

В каталоге шесть реальных компаний с официальными источниками и датой проверки. Неизвестные цены, партии и условия доставки обозначены явно. Серверная часть на Python/SQLite предоставляет API каталога; опубликованная статическая демонстрация работает самостоятельно. Применение LLM для разбора запроса возможно следующим этапом: в текущем прототипе используется детерминированный разбор, который не выдумывает поставщиков и условия.
